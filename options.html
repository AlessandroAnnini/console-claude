Uncheck to let Claude run evals without prompting. Same flag: claude.config.confirm.

In the console

  1. Open DevTools on a normal http(s) page. After reloading the extension, close DevTools and open it again.
  2. Type claude('Inspect this page').
  3. Select a node in Elements, then claude($0) or claude.inspect($0).
  4. Cancel with claude.stop(). Help: claude.help().
